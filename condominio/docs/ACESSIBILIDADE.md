# Acessibilidade e moradores idosos

O condomínio tem muitos moradores idosos. Por isso, cada tela segue as regras abaixo.

## Decisões de design

| Regra | Como foi feito |
|---|---|
| Letra grande por padrão | O app já abre em “Grande” (texto base ~22 pt). Em *Mais → Tamanho da letra* há 4 níveis, que se somam ao tamanho escolhido no celular |
| Contraste forte | Cores com contraste mínimo de 7:1 (WCAG AAA). Opção de **alto contraste** (preto puro, bordas grossas) |
| Alvos grandes | Toda área de toque tem pelo menos 56 pontos de altura (o recomendado é 44–48) |
| Ícone nunca sozinho | Botões e abas sempre têm texto escrito |
| Navegação simples | Apenas 4 abas; tela inicial com quadrados grandes agrupados por assunto |
| Linguagem simples | “Pedir um conserto” em vez de “Abrir chamado”; “Entrou/Saiu” em vez de “Receitas/Despesas” |
| Sem senha | Login com código de 6 números enviado ao e-mail; a sessão fica salva |
| Código de unidade em papel | A síndica imprime cartões com o código de cada unidade (*Gestão → Unidades → Imprimir cartões*) |
| Sem calendário pequeno | Reservas mostram uma **lista de dias** com “LIVRE”/“Ocupado” escrito |
| Sem menus suspensos | Escolhas são botões grandes lado a lado |
| Datas fáceis | Atalhos “Hoje / Amanhã” e digitação com barras automáticas |
| Proteção contra toque sem querer | Ações importantes pedem confirmação (“Sim, confirmar” / “Não, voltar”) |
| Ouvir em voz alta | Avisos, enquetes, regras e textos legais têm o botão **Ouvir** |
| Emergência à mão | Botão vermelho “Emergência: telefones” na tela inicial; um toque liga |
| Leitores de tela | Rótulos e papéis de acessibilidade para VoiceOver (iPhone) e TalkBack (Android) |
| Mensagens de erro claras | Ex.: “Sem conexão com a internet. Verifique o Wi‑Fi…” em vez de códigos técnicos |

## Implantação no condomínio (sugestões)

1. **Mutirão de instalação**: um sábado no salão de festas, com a síndica e voluntários instalando o app junto com quem precisar.
2. **Padrinhos digitais**: vizinhos mais jovens que se oferecem para ajudar um morador idoso.
3. **Cartão com o código** entregue em mãos, com o passo a passo impresso no próprio cartão.
4. **Continuar imprimindo os avisos importantes** no mural — o app soma, não substitui. A gestão vê quantas pessoas abriram cada aviso e sabe quando reforçar no papel.
5. Familiares podem usar o mesmo código da unidade para entrar como “Familiar” e acompanhar pelos pais.

## Testar

- No iPhone: *Ajustes → Acessibilidade → Tela e Tamanho do Texto → Texto Maior* + VoiceOver.
- No Android: *Configurações → Acessibilidade → Tamanho da fonte* + TalkBack.
- Testar com 2 ou 3 moradores idosos reais antes de divulgar para todos, observando onde eles hesitam.
